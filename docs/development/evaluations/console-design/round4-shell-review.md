Reviewed the actual application before inspecting any repository source or previous critique. All screenshots and probes in this folder are independent. Final evidence uses `clean-final-*`, `verified-mobile-*`, `compact-models-deeplink.png` and `final-real-zero-cache-*`; older screenshots document defects that were subsequently fixed.
