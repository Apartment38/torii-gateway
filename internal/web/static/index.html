Custom benchmarks · upload and edit

Upload a CSV to add custom measurements. Matching model, benchmark, category and version rows replace prior custom values. Other rows remain. Enable and save benchmark intelligence first.

Download CSV template

external_model_id
Exact provider/model ID or a configured benchmark alias. Approximate matches do not affect routing.
benchmark
Name of the evaluation, for example my-coding-eval.
category
coding, agentic, knowledge, reasoning, math, instruction_following, multimodal, preference, general_intelligence, operational or unknown.
original_score
Finite numeric measurement in the original scale.
normalized_score
Optional score from 0 to 1, higher is better. Leave blank for unknown or operational measurements. For a percentage, divide by 100; invert lower-is-better scores.
unit
Optional original unit such as percent. Operational benchmarks use input_price/output_price (USD_per_million_tokens), latency/ttft (seconds), throughput (tokens_per_second) or context_length (tokens).
version
Optional evaluation version. Part of the custom row identity.
evaluated_at
Optional UTC RFC3339 evaluation time, for example 2026-10-01T00:00:00Z. Upload time is recorded separately.

Model pricing · import CSV

Enter missing model rates using Edit pricing on a model, or upload a CSV. Manual rates are saved across restart and apply to all routers and estimated usage. Blank rate fields restore automatic pricing; zero means free. A provider's Treat models as free setting overrides entered rates.

Smart routing

Double-click a provider or model to move it between columns, or select entries and use Enable / Remove. An empty enabled provider list allows all providers. Maximum 250 models per router. An empty enabled list allows all models from allowed providers, up to 250; larger pools require an explicit selection. Each router has its own settings. Clients select the router by its model name.

Jev chooses the cheapest capable model using prices, capabilities and relevant benchmarks for each prompt. Torii verifies availability and your routing policy before dispatch.
